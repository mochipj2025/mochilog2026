# 言語化の壁を壊す：AI知性の翻訳プロンプト集

「言いたいことはある。でも、言葉にならない」

それは、あなたの感覚（Body）が鋭すぎるからです。

しかし、知っておいてください。**「自分の想いを言葉にできると、驚くほど施術に自信が持てるようになる」**という事実を。

自分の意図を明確に言語化できたとき、迷いは消え、それは指先を通じてダイレクトに相手の神経へと伝わります。言語化は、単なる発信ではなく、あなた自身の「手」を研ぎ澄まし、施術の純度を高めるための儀式なのです。

このラボでは、その「名もなき感覚」をAIというフィルターに通し、他者に届く「物語（Story）」へと変換するための魔法を共有します。

以下のプロンプトを、ChatGPTやGeminiにコピー＆ペーストして使ってください。

---

### 1. 【臨床の火花】抽出プロンプト
**用途**: 患者さんの不思議な反応や、言葉にできない違和感を言語化したいとき。

```markdown
あなたはBNS理論（Body・Nerve・Story）の専門家です。
私の以下の臨床的な違和感を、3つの視点から解体してください。

【状況】
[ここに状況や違和感を自由に入力]

【依頼】
1. Body（筋骨格・筋膜）の視点で、どの起始停止やラインが関与していそうか？
2. Nerve（神経系）の視点で、交感・副交感のどちらがどう揺らいでいるか？
3. Story（物語）の視点で、この症状が相手の人生のどんな文脈を語っているか？

学術的な専門性と、現場の生々しい洞察を組み合わせて回答してください。
```

---

### 2. 【脱・聖人君子】本音翻訳プロンプト
**用途**: 綺麗事ではない、現場の「黒い感情」や「生々しい葛藤」を、ブランドを壊さずに発信したいとき。

```markdown
以下の私の「本音」を、知的でハードボイルドな文体にリライトしてください。
「ポエム」や「AIらしい当たり前の結論」は徹底的に排除してください。

【私の本音】
[ここに愚痴や葛藤をそのまま入力]

【リライトの指針】
- 読者を否定せず、しかし現実に冷徹に向き合う「安全基地」としてのトーン。
- 短い文章、ブラケット見出し `[ ]` 、意図的な一行空きの多用。
- プロフェッショナルとしてのプライドは守りつつ、不完全さを隠さない。
```

---

### 3. 【産業化】note構成プロンプト
**用途**: ただの独り言を、価値ある「有料記事（資産）」に変えたいとき。

```markdown
以下の思考の断片を、noteで100円〜500円で販売可能な「知的資産」としての構成案にしてください。

【素材】
[ここにメモや考えを入力]

【構成案の必須要素】
1. タイトル（32文字以内、ベネフィットと意外性を入れる）
2. リード文（読者が抱える「孤独」に寄り添い、解決策を提示する）
3. 目次（BNS理論に基づいた3つのセクション）
4. Lab（クローズドエリア）への誘導のタイミング
```
